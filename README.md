# Stack-N-Dink
Offline First Pickleball stacking app with Presenting Mode 

**Course:** CPE 3121 – Software Development Strategies
**School:** University of San Carlos, Department of Computer Engineering
**Team:** Team 3

## About

Stack n Dink helps pickleball hosts organize court rotations. The host sets the
number of courts, adds players, picks a stacking mode, and can move players or
change partners at any time. When a court finishes, Presenting Mode shows and
announces the next players and the open court.

## Features (planned)

- Session setup: courts, players, teams, no sign-in
- Stacking modes: FIFO, Win-Win/Lose-Lose, Winner Stays, skill-based
  matchmaking, round robin, tournament
- Manual override: move players, change teammates, edit the queue
- Presenting Mode with on-screen names, court number, and voice announcements
- Basic tracking of player turns, court availability, and match results

## Project Goals

- Presenting Mode announces next players within 3 seconds of a court finishing
- At least 20 game rotations tested with no duplicated, lost, or skipped players
- At least 80% of test users can set up and start playing within 3 minutes
